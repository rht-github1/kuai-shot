# 快截图（Ubuntu 24.04）

面向 GNOME / Wayland 的区域截图工具：开机自启动、置顶全屏遮罩、选区标注后复制或保存。

## 功能

- 全局快捷键 **Ctrl+Alt+A**
- 多显示器：每块屏单独抓图、单独遮罩，1x / 2x 混缩放可用
- 全屏置顶遮罩，拖拽选区、八向缩放、移动选区
- 矩形 / 椭圆 / 箭头 / 画笔 / 高亮 / 马赛克 / 文字
- 颜色与线宽、撤销 / 重做、保存、复制到剪贴板
- 原图像素导出，不二次压缩、不拉伸降质
- 钉在屏幕最上层，可拖动，右键或双击关闭
- 登录后自动拉起托盘守护进程

## 安装

```bash
cd kuai-shot
./install.sh
```

安装后会：

1. 复制到 `~/.local/share/kuai-shot`
2. 写入 `~/.local/bin/kuai-shot`
3. 写入 `~/.config/autostart/kuai-shot.desktop`（开机/登录自启）
4. 注册 GNOME 自定义快捷键 `Ctrl+Alt+A`

若快捷键未生效：设置 → 键盘 → 查看自定义快捷键是否为「快截图」。

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖拽 | 在当前屏幕选择区域 |
| 双击空白 / Enter（未选区） | 截取当前这块整屏 |
| 数字键 1-9 | 直接截取对应那块整屏 |
| Enter / 双击选区 / ✓ | 复制到剪贴板并关闭 |
| Esc / ✕ | 取消 |
| Ctrl+C / Ctrl+S | 复制 / 保存 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| 右键 | 取消 |
| 📌 | 复制并钉在最上层 |

托盘图标单击也可开始截图。
